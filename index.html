Cross Cleaner removes temporary files, caches and leftover system junk. It ships as a native window app, as a terminal app and as a command line app, and it builds for Windows, macOS, Linux and Android — x86_64 and arm64 alike.

Features

Built to be small, fast and hard to break

One portable file per platform, with no runtime to install and no background service left behind.

Multi-threaded by default

Work is spread across cores with rayon, so a full sweep finishes in seconds instead of walking the disk one file at a time.

Careful with what matters

Critical system files are protected. Clean entries are hand-maintained per platform and reviewed before they ship.

Four platforms

Windows, macOS, Linux and Android, each with its own program database, plus native arm64 builds on Windows and Linux.

Three ways to drive it

The GUI is egui, the TUI is ratatui and the CLI is clap — all three on the same engine and the same database. Pick the surface that fits the moment.

Updates itself

Binaries check the release feed and replace themselves in place. The Windows installer is skipped during an in-app update, since it needs elevation.

Bring your own database

Every list is a plain JSON file you can edit or extend. Programs, registry entries and paths all live in open catalogs.

Alternatives

Coming from CCleaner or BleachBit?

Both do the same job this app does. Here is the honest version of the comparison: what differs, and what does not.

A CCleaner alternative

CCleaner is a mature cleaner, and on Windows alone it does the job well. Cross Cleaner differs in the catalog rather than in the promises: every program it cleans is named and published — 262 programs across 564 concrete paths on Windows, spanning browsers, launchers, IDEs, games, antivirus and VPNs — so the coverage can be checked instead of taken on trust. The same single portable file also adds macOS, Linux and Android, with no runtime to install.

Free, GPL-3.0 macOS, Linux, Android No install

A BleachBit alternative

BleachBit is open source, cross-platform and well established, so take this as a real option and not an upgrade. Cross Cleaner differs in three specifics: it builds for Android as well, it ships a native terminal app and a scriptable command line app next to the window app, and its cleanup catalogs are published in full — 262 programs across 564 paths on Windows, 71 programs across 162 paths on Linux, every one of them listed by name in the repository.

Also builds for Android GUI, TUI and CLI Public catalogs

Why it goes further

On both counts. Work is spread across every core with rayon, so a sweep hits the disk in parallel instead of one file at a time, and the Windows catalog maps 262 programs onto 564 concrete paths — browsers, launchers, IDEs, games, antivirus, VPNs — so it reaches the leftovers those applications leave behind rather than stopping at the obvious temp folders. Read the full catalog and check the counts for yourself.

Interface

One engine, three surfaces

Under the hood

Small on disk, quiet on the CPU

The release profile trades a little throughput for a noticeably smaller executable. Nothing here is bound tightly enough for that to show.

z opt-level, plus LTO, one codegen unit, stripped symbols and no unwinder
4 platform databases, minified and gzipped into the binary at compile time
15 published binaries: Windows, Linux and macOS, window, terminal and command line, two architectures
1 file per download — portable, nothing installed, nothing left behind

The cleanup catalogs are public

Every program Cross Cleaner knows about is listed in the repository, so you can read exactly what gets removed before running anything.
